# 餐厅（？ · 随机 checkpoint 专注计时器

一间不保证好吃的虚构餐厅。每轮 session 对应一道随机怪菜，12 道菜最近 4 轮不重复。采用原创 SVG 菜品插画、奶油黄与番茄红界面。

一个无依赖的静态网站。页面资源都在 `dist/`，没有后端、外部字体或分析服务。图书馆录音随网站一起提供，运行时不依赖第三方音频链接。

本地运行：`python3 -m http.server 4173 --directory dist`，打开 http://localhost:4173。

默认 session 为 90 分钟，包含 checkpoint；手动暂停不计入时长。每次 checkpoint 结束后重新随机抽取 8–15 分钟间隔，checkpoint 默认持续 20 秒并自动结束。不显示下一次 checkpoint 的倒计时。

90 条中文提示：休息 45%、复习 20%、随机奖励 35%。最近 24 条不重复。6 种轻量动画，支持系统减少动态效果偏好。

浏览器本地存储保存设置和累计大循环次数；刷新会结束当前 session。声音通过 Web Audio 生成：低通柔化白噪音、合成爵士和弦与柔和提示音。环境声默认关闭，顶部静音控制所有声音。

计时以绝对截止时间计算，与渲染及动画分离。后台标签页延迟更新后会按实际时间校正。系统锁屏或冻结浏览器仍可能延迟提示与声音；支持时会在运行期间请求保持屏幕唤醒。

验证：`node tests/timer.test.mjs`。

Checkpoint 会显示本轮第几个小循环和已进行时间。90 条提示各配一句语境相关夸奖，并按本轮总时长的前三分之一、中间三分之一、后三分之一改变进度夸奖。

完整完成一次 session 计为一次大循环（自定义时长也适用）。结账页显示本设备累计大循环次数和本次打开完成次数；从此版本开始统计。暂停、重置、刷新导致的未完成 session 不计入。同一完成状态只记一次。累计次数用本地存储保存，存储不可用时页面会提示新增记录可能丢失。

新增验证：`node tests/encouragement-cycles.test.mjs`。

店名为「餐厅（？」（just a diner）。专注及专注暂停阶段隐藏总剩余时间、时间标题、总进度条和底部进度文字；checkpoint 阶段显示计时。设置页与完成页保留原有时间展示。


## 图书馆声景

在「餐厅收音机」选择图书馆或柔和白噪音。开启专注声景后，图书馆使用柔和的合成底噪与缓慢音量起伏，随机叠加真实翻书、杯勺和远处低语。远处人声有独立开关，声音偏好随设置保存在本地。15 秒试听仅在未开始或已完成 session 时可用；试听会取消静音。

正式播放的重复间隔：翻书 25–80 秒，杯勺 2–5 分钟，人声 3–7 分钟，原创合成充电提示音 5–12 分钟。首次入场会使用较短的随机等待，让声景更快出现。每次播放后重新随机；同类有多条录音时避免连续重复同一条；最多同时两种短音效。暂停、静音、重置、结束或进入 checkpoint 时清除随机调度，并让环境声淡出。checkpoint 爵士、提示音沿用原机制。

素材位于 `dist/assets/audio/`：9 段单声道 24 kHz WAV，来自 5 条 CC0 原始录音（OwlStorm、kikuchiyo、SpliceSound）。作者、来源网址、许可及处理说明位于 `credits.json`，网页的「音效来源与说明」也提供直接链接。所有片段已滤波、剪辑、保守归一化并淡入淡出；充电声与底噪为原创合成。

发布版从本站载入音效；根目录 `index.html` 已内嵌全部录音，可直接离线打开。声音内容在首次需要时解码并缓存。部分录音加载失败会显示提示，其余音效继续播放，计时不受影响。

音频调度验证：`node tests/library.test.mjs`（模拟音频节点，覆盖素材格式、随机范围、去重、重叠上限、人声开关、停止后调度取消、异步加载竞态、缺失素材降级及声音模式切换；不代表真人听感验收）。

## 使用与发布

直接打开根目录 `index.html` 即可使用，音效已经嵌入，不需要安装依赖或连接 Freesound。

- `dist/`：可编辑的网页源码与音频素材。
- `tests/`：计时、循环统计和音频调度测试。
- `scripts/build.py`：将源码合并为根目录的独立网页。

修改源码后，在仓库目录运行 `python3 scripts/build.py`，将更新后的源码和 `index.html` 一起提交。

运行验证：

```sh
node tests/timer.test.mjs
node tests/encouragement-cycles.test.mjs
node tests/library.test.mjs
```

GitHub Pages 使用 `main` 分支根目录发布，入口为 `index.html`。本地文件与在线网站的浏览器存储相互独立，原来的设置和累计次数不会自动迁移。
